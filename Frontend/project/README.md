# Smart Canteen Management System

A complete, modern, responsive AI-powered frontend for a Smart Canteen Management System built with pure HTML5, CSS3, and JavaScript (no frameworks).

## Theme
- Primary: Orange (#FF7A00)
- Secondary: White (#FFFFFF)
- Accent: Light Gray (#F5F5F5)
- Font: Poppins
- Glassmorphism + Soft Shadow UI

## Folder Structure
```
├── index.html              # Welcome / Landing page
├── css/
│   ├── style.css          # Global theme, components, utilities
│   ├── auth.css           # Auth + welcome page styles
│   └── dashboard.css      # Dashboard layout, navbar, sidebar, cards
├── js/
│   ├── app.js             # Auth, cart, toast, modal, helpers
│   └── data.js            # Food menu dummy data (100 items)
├── pages/
│   ├── register.html       # User registration
│   ├── login.html         # User login
│   ├── admin-login.html   # Admin login
│   ├── dashboard.html     # Student home dashboard
│   ├── menu.html          # Food menu (all categories)
│   ├── food-details.html  # Food details page
│   ├── cart.html           # Shopping cart
│   ├── order.html         # Order tracking
│   ├── order-history.html # Order history
│   ├── qr-scanner.html    # QR food scanner
│   ├── upi-payment.html   # UPI payment
│   ├── smart-card.html    # Virtual smart card
│   ├── wallet.html        # Digital wallet
│   ├── profile.html       # Student profile
│   └── admin-dashboard.html # Admin dashboard
├── assets/
│   └── images/           # Local image placeholders
└── images/               # Legacy folder (empty)
```

## Features
- 100+ food items across 9 categories
- Glassmorphism cards with soft shadows
- Smooth animations and hover effects
- Fully responsive (mobile, tablet, desktop)
- Cart, favorites, and order management
- UPI payment with QR code
- Virtual smart card with transaction history
- Digital wallet with recharge
- QR food scanner UI
- Admin dashboard with management tools
- JavaScript form validation
- Dummy JSON data ready for backend API integration

## Running
The dev server runs automatically. Open the app to view the welcome page.
